Connect your GitHub key

Saving needs a key that only you have. It is stored only in this browser on this device.

  1. Open GitHub → New fine-grained token.
  2. Name it “portfolio admin”. Under Repository access, pick Only select repositories → your portfolio repo.
  3. Under Permissions → Contents, choose Read and write. Generate it and copy it.
